The main Worker embeds WASM and the picture-worker program. No separate
.wasm or picture-worker JavaScript request is needed for this build.
Source maps and TypeScript declarations are development artifacts and are
not vendored.

aribb24.mjs is served as aribb24.js so the existing Chinachu WUI supplies
the expected JavaScript MIME type.

LICENSE covers the mpeg2toh264 player runtime.
LICENSE.aribb24 covers the aribb24.js caption runtime.

The caption adapter follows the upstream demo's Controller,
MPEGTSFeeder and SVGDOMRenderer arrangement.

Player defaults used by the Chinachu adapters include:
- oversample: 2
- recoveryInterval: 24
- splitFieldSamples: true
- automatic MSE / ManagedMediaSource selection
- passthrough: disabled
- deinterlace: disabled

The upstream demo diagnostics, tuning controls and optional yadif filter
are not bundled.

Recorded playback integration:
- adapter: ../recorded-player.js
- input: /api/recorded/:id/file.m2ts
- recorded file API supports HTTP byte ranges
- upstream Range seeking is used by the native seekbar
- ArrowLeft / ArrowRight provide Chinachu 15-second seeking
- playback starts only after the viewer explicitly opens the player

Live playback integration:
- adapter: ../live-player.js
- input: /api/channel/:chid/watch.m2ts
- the existing Chinachu / Mirakurun live MPEG-2 TS stream is used directly
- no Range or timeshift behavior is required for live playback
- the shared live overlay is used from the schedule and dashboard TOP pages
- live programme title, detail, time and progress follow the latest schedule

Caption and fullscreen behavior:
- ARIB Caption and Superimpose are rendered with aribb24.js SVG overlays
- the caption toggle controls Caption while Superimpose is retained
- Chinachu fullscreen targets the containing stage so SVG captions remain visible
- where element fullscreen is unavailable, the player expands within the browser viewport
- browser-native video fullscreen may not contain the external SVG caption overlay

Resource cleanup:
- recorded playback releases the player and caption resources on teardown
- live playback releases the player, Worker, stream request, caption resources,
  timers and event listeners when closed or when the page is left
